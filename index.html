About / Install as app

SW MatSide · Live score + record for the mat side.

Install from a downloaded file is limited: browsers only offer “Install app” when the page is served over https:// (not from Downloads / file://).

Workarounds:
· Android: Chrome ⋮ → Add to Home screen (shortcut; may still work from a file).
· iPhone: open the file in Safari → Share → Add to Home Screen.
· Best: host this HTML on any free https host (Netlify, GitHub Pages, etc.), then Install app.
